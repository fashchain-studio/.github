# Fashchain Studio

> 唯有過好每一天，才能串連出生命的價值。

## 關於我們

Fashchain Studio 是一家位於台灣的數位育兒工具開發公司，專注於研發溫暖且精準的解決方案，將日常生活片段透過技術與設計進行整合。

## 我們的產品

### 初日手帳

AI 育兒助手，陪伴新手爸媽的每一天。

- 記錄寶寶副食品資訊
- 追蹤幼兒作息與成長發展
- 科學化的育兒數據分析
- 100% 隱私安全保障
- 24/7 AI 智能助手
